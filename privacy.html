개인정보처리방침

시행일: 2026-10-16

1. 이용 범위

10조 쇼츠(이하 "앱")는 운영자 본인의 Google 계정에만 연결되는 개인용 자동화 도구입니다.

2. 사용하는 Google 데이터

  • YouTube Data API: 운영자가 만든 영상을 운영자 본인의 채널에 업로드하고 업로드 결과를 확인합니다.
  • Gmail API(발송 전용): 운영자 본인에게 업무 보고 메일을 보냅니다. 받은편지함을 읽지 않습니다.

3. 보관과 공유

인증 토큰은 운영자 컴퓨터에만 저장되며 외부 서버로 전송하거나 제3자와 공유하지 않습니다. Google 사용자 데이터를 판매하거나 광고에 사용하지 않습니다.

앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

Google 계정 권한 페이지에서 언제든 앱의 접근 권한을 철회할 수 있습니다.
